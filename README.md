# Ledger — Expense Tracker Web Application

Ledger is a responsive and interactive Expense Tracker web application built using HTML, CSS, and JavaScript. It helps users manage their income and expenses efficiently with real-time balance tracking, category-wise spending analysis, and transaction management.

## Features

- Add and manage income & expense transactions
- Real-time balance, income, and expense calculation
- Category-wise expense breakdown with visual progress bars
- Transaction filtering (All / Income / Expense)
- Local storage support for data persistence
- Responsive and modern UI design
- Monthly grouped transaction history
- Delete transaction functionality

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Local Storage API

## Project Structure

├── index.html
├── style.css
├── script.js

## How to Run

1. Download or clone the repository
2. Open the project folder
3. Run the `index.html` file in your browser
